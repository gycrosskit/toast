# 0.1.3 候选验收

独占 remote-dependency-closure/toast worktree。候选增加 Kotlin dispose 与原生 onDestroy 消息门禁；全进程唯一 presenter 继续负责新消息替换，旧 Page 销毁不能关闭后继 Page 的 Toast。未修改生产宿主。

## 已执行的轻量检查

- `node tests/kuikly-module.cjs` 执行实际 ArkTS Module/Presenter：非法输入与时长、空白、缺少 context、旧 openToast 迟返回后的串行关闭/替换、销毁 Page 的迟消息，以及旧 Page 不关闭新 Toast 均通过。
- `bash -n jitpack-install.sh` 和 `git diff --check` 通过。安装器沿用固定 tag 对应 SHA 校验与原字节安装，无消费端 Python。
- 独立 consumer 默认 0.1.3：Android/iOS 引用 core/CMP CompositionLocal，OHOS 引用 ToastModule.show/dispose。CMP 没有 OHOS 变体，依赖仅加在 Android/iOS sourceSet。
- 两阶段 normalizer 的 6 项纯文件测试通过：空 ZIP 与根转发一起移除，非空/零字节真实文件必须失败且不写任何 metadata，缺目标失败，API 保留，四种 sidecar 更新。
