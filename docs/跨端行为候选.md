# 0.1.4 跨端行为候选（未发布）

`MessageOverlayState` 是唯一消息状态 owner，也是 `MessagePlatform`；CMP Android/iOS 和 Kuikly Compose Android/iOS/OHOS 的 `MessageHost` 复用同一状态合同与 `MessageOverlaySpec`。两个 render 入口仅使用各自 Foundation/UI 类型；CMP 不提供 OHOS 变体。

在已处理系统安全区域的页面根部 `remember { MessageOverlayState() }`，用对应包的 `MessageHost(state) { content() }` 装配。Host 自动提供 `LocalMessagePlatform`，子组合用 `rememberMessages()` 取得同一实例，DI 调用方也可直接注入该 state。每个 Host 独占实例；移除 Host 终态关闭，重建页面需新实例。空白忽略、新消息替换并重新计时、旧 dismiss 不影响新消息。

规格：安全区域顶部居中，外间距 16dp，内横/纵 18/12dp，圆角 12dp，最大宽 520dp，14sp 字/20sp 行高，背景 `0xD6000000`、白字，SHORT 2000ms、LONG 3500ms，Polite live region，应用内 overlay 不消费点击。字号/安全区域和设备渲染需宿主验收。

保留 Android/iOS/OHOS 原生 legacy API；其系统 UI 仍由系统控制。旧 `ToastModule` 的配套 native bridge 只有 OHOS，不作为 Android/iOS overlay 驱动。Swift legacy LONG 调整为 3.5s；未改 OHOS native 源码，Maven 0.1.4 可继续配对 HAR 0.1.3；Swift Package/Git Pod 需新 tag 0.1.4。未发布、未远程消费。

新增 `toast-kuikly-android/iosarm64/iosx64/iossimulatorarm64`，共 17 publications；公开 UI/Core 类型已使用 `api` 依赖。源码五组合编译和独立本地 Maven UI consumer 已通过；设备视觉与无障碍尚未验收。新版本远程消费必须加 `-PverifyUnifiedUi=true`，旧标签 baseline 继续关闭该探针。
