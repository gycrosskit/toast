# 功能与平台差异

当前源码：Maven `0.2.0-rc.2`，尚未发布。仅保留 `toast` 与 `toast-kuikly`，移除 `toast-cmp` 生产代码/API、CMP 探针与构建门禁；这是不兼容候选，旧 CMP 使用方继续锁定 `0.1.x` 或迁移。KuiklyCompose/compiler/runtime、共享 state 与三端 native 能力保持。

原生 Git Pod 元数据保持 `0.1.6`，OHOS HAR 保持 `0.1.3`，本次未重发；历史记录与当前候选源码/消费验证分开。接线见[指南](接入指南.md#androidios-native-module)。

组件提供宿主已本地化的短消息展示。优先区分应用内 `MessageHost` Overlay 与 legacy 系统/原生 presenter：前者在 KuiklyCompose Android/iOS/OHOS 消费共同状态与规格；后者受 Android Toast、UIKit UIWindow、OHOS PromptAction 控制。两种路径均可使用，视觉与生命周期合同不能混称完全一致。

## 公开功能与合同

- `MessagePlatform.show(message, AppMessageDuration)` 在trim后忽略空白，`show(message)`默认SHORT。Overlay精确SHORT=2000ms、LONG=3500ms；legacy原生路径只消费时长档位，实际时长受系统/presenter控制。
- `MessageOverlayState` 使用requestId替换旧消息；迟到dismiss不能移除新消息，`dispose`为终态。Host 的 timer按state/requestId归属，宿主负责正确挂载Host与释放state。
- `ProvideMessagePlatform`/`LocalMessagePlatform`/`rememberMessages` 注入宿主实例，缺少provider明确抛错，不隐式使用全局fallback。
- Overlay 规格：outerPadding16、horizontal18、vertical12、corner12、maxWidth520、fontSize14、lineHeight20，背景D6000000、文本FFFFFFFF，polite liveRegion。Kuikly背景/padding用独立Box以适配其Text布局；这些源码参数一致不代表字体/多行/朗读已通过设备验收。
- legacy `ToastModule.show`是无回调异步转发；dispose阻止新转发，已显示消息归共享native presenter管理。Swift 需稳定 rootController 绑定及 `GycToastNative/Kuikly` 类型引用；Android 需每 Renderer `registerToastModule`；OHOS 需原生 Module 注册及 UIAbilityContext。0.1.5 的 A/i 客户端缺少原生接收端，不能以客户端编译作为端到端支持。

## Kuikly 三端能力矩阵

S=源码已实现并核对平台接线，不代表设备/业务验收；U=当前特定能力或输入Unsupported/无对应实现；V=需要内核/设备证据，尚未验收；E=按本轮要求排除。真实回归范围单列在下文，不能把S总数当“全部通过”。分组列列出功能语义/定位关键词，S不承诺每列存在同名API；专属入口/参数另列，具体类型以源码与模块职责为准。

| 功能/API组 | 成员/行为关键词（内部关键词不是公开API） | Kuikly Android | Kuikly iOS | Kuikly OHOS |
| --- | --- | --- | --- | --- |
| `Composition provider / host` | `ProvideMessagePlatform, LocalMessagePlatform, MessageHost, state, modifier` | S | S | S |
| `Message API / duration` | `MessagePlatform.show, message, duration, AppMessageDuration.SHORT, AppMessageDuration.LONG` | S | S | S |
| `Overlay state / lifecycle` | `requestId, text, duration, disposed, show, dismiss, dispose` | S | S | S |
| `Overlay style / accessibility` | `outerPadding, horizontalPadding, verticalPadding, cornerRadius, maxWidth, fontSize, lineHeight, backgroundColor, textColor, liveRegion` | S | S | S |
| `Legacy native presenters` | `AndroidMessagePlatform, IosMessagePlatform, IosMessageBridge, GycToastModule, rootViewController` | S | S | S |

## 差异分类与使用边界

| 分类 | 当前合同与限制 |
| --- | --- |
| 组件入口 | KuiklyCompose 提供 Overlay provider/Host；legacy native presenter仍保留。不能只调用legacy show后按Overlay规格验收。 |
| OS/SDK边界 | 原生AndroidToast/UIKit/OHOS提示视觉与时长受系统/原生实现约束；Kuikly Text布局需Box背景/padding。 |
| 宿主输入 | 文案/语言由宿主提供，缺provider明确失败；native桥、rootController、OHOS注册/context与释放归属必须正确。 |
| 未验收 | 三端实际字体倍率、长多行、深浅色/居中、屏幕朗读与真实OHOSPromptAction时序未本轮设备验收；共同Spec/状态机与编译不能替代。 |
